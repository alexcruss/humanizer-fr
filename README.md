# humanizer-fr

Skill Claude qui écrit et relit les textes en français sans les tics d'écriture d'IA.

Il contient la liste complète des tics, rangés en quatre groupes (mots, structure des phrases, ton, typographie et mise en forme), avec pour chacun ce qu'il faut écrire à la place. Il se termine par une relecture obligatoire avant de rendre un texte : chaque tic restant est corrigé, sans changer le sens, les chiffres ni les noms.

## Installation

Copier le dossier `humanizer` dans le dossier des skills de Claude (par exemple `~/.claude/skills/`).
